# 已确认的美术方向

以用户认可的「豁然开朗」「缘溪桃林」两张 imagegen 概念图为参考。画风采用亲切的卡通人物、简化手绘材质、明亮春日配色和有层次的国风山水。所有图片是概念设计，不代表当前 Three.js 游戏的实际渲染质量。

## 统一规范

- 渔人：斗笠、青蓝布衣、棕色裤装、竹编背篓，略大头小身的亲切比例。
- 建筑：朴素中国农家，奶油灰墙、木构、灰绿瓦顶、木窗棂；不使用神社、鸟居或夸张殿宇。
- 环境：清透青绿水色，草地与桑竹以嫩绿、鼠尾草绿为主，山外桃林用柔粉与珊瑚粉。
- 光照：温暖晨光、柔和阴影、哑光手绘质感。结尾沿用同一世界，增加薄雾和冷色，不转成恐怖风格。
- 轮廓：树木可见分枝，山体有岩层，不使用巨型球状树冠或堆叠石球代替主要形态。

## 六幕与空间关系

1. 缘溪桃林：山外的溪水两岸皆为桃树，渔人行舟，尚未看到村庄。
2. 桃林尽头：溪流源头、山脚小洞、微弱自然光；渔人系舟上岸。洞口仅容一人。
3. 豁然开朗：穿洞后发现开阔平原、整齐村舍、良田池塘、桑竹和往来的村民。
4. 田园日常：村内近景，耕种、老人孩子、鸡犬，展示安宁的生活。
5. 村舍待客：农家室内及小院，酒饭款待与对话；剖面适合转化为可探索室内。
6. 重寻不得：回到山外，旧路标记仍在，雾中找不到洞口；与开场构图呼应。

## 2026-09-07 实现与差距记录

用户指出程序场景与概念图差异明显后，暂停向其他五幕复制美术，先集中重做缘溪桃林。

已实现：imagegen 透明桃花簇贴图用于多方向 3D 叶片卡；imagegen 草地漫反射贴图；弯曲枝干；起伏河岸；远景柔和山坡；降低水面规则纹路；漂浮花瓣；调整小舟与镜头位置。依然是真实 Three.js 网格场景，可旋转缩放，未使用整张概念图冒充 3D 渲染。

仍有明显差距：角色与小舟模型较简单，树木分枝与树冠轮廓仍为程序生成，远山、岩石、水体材质未达到概念图的美术完成度。因此不可将本版描述为已还原概念图。其他场景只有基础布局与玩法，不表示美术已完成。

最新实机截图：`artifacts/grove-v2.png`（含界面）与 `artifacts/grove-v2-clean.png`（场景画面）。概念图：`assets/concepts/01-peach-stream.png`。

## v3 路线与碰撞验收

新增实际溪尾码头和山口、自动系舟上岸、可通行的狭道、各场景入口触发区，以及跟随行舟的镜头。水纹使用沿河 UV 流动，泡沫与花瓣随河道移动，小舟增加尾波。

室内人物站立基准统一到地板高度，主人移出座椅占位；修正桌椅支腿高度。通过碰撞地图和 A* 寻路防止角色穿过家具，按室外、台阶、室内地板分别计算脚底高度。已验证完整六幕行进、键盘抵挡障碍，以及真实鼠标点击桌后地面后绕桌到达。
