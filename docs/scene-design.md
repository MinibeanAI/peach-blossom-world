# 桃源场景设计

## 文章大意

武陵渔人沿溪误入桃林，穿过山口发现一个与世隔绝的村落。村民过着安宁的农耕生活，热情款待来客。渔人离开时做了记号，后来却再也寻不到原路。

## 画面与交互

俯视微缩山谷为入口，粉色桃花沿青绿溪水生长，木桥连接两岸，灰绿瓦屋与稻田、池塘分布在山谷中。奶油纸色界面和宋体诗句保持安静的阅读感。暖光与软阴影、飘落花瓣和水面细纹形成春日氛围。

1. 桃花渡：环绕木桥的桃林、水边小舟与码头；收集一瓣桃花。
2. 山间秘境：狭长石壁夹道、侧面溪水与尽头暖光；收集一束天光。
3. 桑竹田园：稻田、竹林、亭子、荷塘与游鱼；收集一片荷叶。
4. 屋舍俨然：可旋转的剖面木屋、窗棂、床榻、置物架与茶桌；收集一盏清茶，可与村人对话。

点击地点进入独立近景，提供漫步、收集、进度保存、手记和结尾。每一景都能自由缩放与旋转，返回全景不会丢失收集进度。
