# 迭代记录

## v3：沿路线游历与碰撞修复

右下角按钮 / E 现在开始沿路行进，再按一次暂停，不直接跳转场景。W / S 仍可手动划船，镜头跟随小舟。到溪流尽头会看到山口与码头，自动靠岸下船；第二幕可步行穿过真实狭道，到出口后过渡到村落。村落、田园、屋内和归途也设置了实际入口；底部六幕卡仍保留快速查看功能。

水流使用沿溪道 UV 移动的纹理、顺流泡沫与花瓣，小舟带尾波。减少树冠重复堆叠，绿叶改成圆润叶形，草丛降低并混合地表贴图，山体改为渐尖的坡面与岩层配色。

待客场景修复了村人陷入地板、主人与椅子重叠，以及家具高度不一致的问题。`navigation.js` 为桌椅、床、置物架、灶台、墙体和村人提供碰撞区域；鼠标点击使用寻路绕行，键盘移动会在障碍前停下或沿边缘滑动。台阶和室内地板有各自的站立高度。

验证记录：`artifacts/verification-v3.json`（完整六幕行进）、`artifacts/collision-ui-v3.json`（真实鼠标绕桌与脚底高度）。美术仍为风格化网页 3D 原型，与概念图的模型和材质精度存在差距。

- 草地、小路、院落的高度统一；室内保留地板高度，台阶采用与模型一致的逐级高度。
- 田园依据第 4 张概念图，移除无梁架的亭子，改为桩柱与底梁支撑的木埠；修正池塘几何缩放和水面密集条纹，重新连接竹枝、树枝与树根。
- 村落、田园和院落使用同一组建筑与山脊造型，补充相邻农舍、田地及通路。仍为分区加载的六幕，不是完全无缝开放世界。
- 验证：`scripts/grounding-v4.cjs`、`scripts/foot-contact-v4.cjs`，以及完整六幕行进检查。


### v7：桃林与山口共用布景
前两幕共用同一条溪流、桃林、码头和实际山洞，洞口坐标接在溪流尽头。上岸时保留镜头与人物位置，取消两幕之间的淡出换景；小舟泊在码头水侧，经过踏板进入岸边小道。第二幕直接进入也使用同一泊船位置。新增 `scripts/approach-v7.cjs` 验证靠岸、连续上岸、沿路穿洞及章节直接进入。


### v8：田园、入席和环境声
- 田园田块退出小路，补充 4 栋农舍和 2 处池塘，新增房屋、池塘、田块碰撞；竹竿逐渐收细并有轻微弯曲，细枝从竹节伸出，窄叶连在枝条上。
- 点击桌边“坐下”会先绕路到凳旁，再坐下；点击“起身”或方向键可继续走。杯盘使用有厚度的器形，壶底与盘底落在桌面，食物、茶水按容器尺寸摆放。
- 点右上“听环境”开启声音：六幕分别混合溪流、风、滴水回声、虫鸟与炉火；切换时渐变。脚步低音量，随步伐触发，在木地板与户外音色不同，停步或坐下时停止。声音为程序合成，并非实地录音。
- `scripts/daily-v8.cjs` 检查实际田块与道路间距、田园到村舍路线、坐下/起身、脚底高度、脚步触发、环境音切换、静音及窄屏。


### v9：有人生活的村落、摇桨与完整院落
- 田园扩展为 8 片贴地田块、11 栋村舍、5 处池塘与相连的道路；12 名动态村民分别往来或劳作，并保留原有村人。土壤边缘使用与地形连续的纹理坐标，去除田块厚底座和穿出土壤的草。
- 行船时双臂握桨，船桨经历入水、向后划水、提桨和回桨，桨边水波与划水阶段同步；停船时恢复搁桨。
- 做客重建为完整屋顶、四面房屋外墙、厢房、围墙、院门和院内桌椅。聊天用餐在院中；坐姿降低骨盆，大腿水平、小腿下垂，臀部贴座面、鞋底落在院地。
- 当前检查入口：`scripts/navigation-v9.mjs`、`scripts/living-world-v9.cjs`、`scripts/approach-v7.cjs`。旧的室内布置与台阶测试保留为历史记录，不再代表现在的院落布局。

### v12：渔人与村民的古代服饰
- 渔人使用灰蓝交领右衽衣、布巾束发、系带与裤装；村民使用麻色、赭色等朴素衣着、较收束的袖形与发髻，长者增加灰发和胡须。移除全员相同的圆斗笠和背篓，缩小头部比例并调整五官。
- 上衣、衣袖与裤装接入原有骨架；分片衣摆随大腿变化，兼容行走和入席；手的位置随划桨时前臂端点更新。
- 这是以魏晋与较早秦汉视觉资料为参考的游戏化人物设计，不是出土服装的精确复原；原文“男女衣着，悉如外人”并不直接支持两组服饰差异，时代对比按本项目用户要求进行演绎。
- 参考：中国国家博物馆《中国古代服饰文化》https://www.chnmuseum.cn/portals/0/web/zt/202102gdfsh/ ；国博《彩绘长袖舞女陶俑》https://www.chnmuseum.cn/zp/zpml/kgfjp/202209/t20220901_257158.shtml （交领参考，非劳动衣着直接复刻）；故宫《顾恺之洛神赋图卷（宋摹）》https://www.dpm.org.cn/collection/paint/234597.html （后世摹本，非原作实物）。
- 验证脚本：`scripts/costumes-v12.cjs` 检查不同角色服饰、聚坐与告辞行走；`scripts/rowing-costume-v12.cjs` 检查渔人换装后的划船动画。

- `scripts/music-ui-v13.cjs` 检查音频非静音与峰值、独立开关、跨场景连续、暂停恢复、截图下载、帮助弹窗和窄屏布局。
